# agents/ — контекст проекта для ИИ-агентов

Краткая выжимка, чтобы новая сессия сразу понимала проект. Подробности — в коде и корневом README.

Порядок чтения:

1. [project.md](project.md) — что за приложение, стек, где что лежит, как запускать и тестировать.
2. [architecture.md](architecture.md) — как это работает в рантайме: контейнеры, порты, путь запроса, CI.
3. `devops-plan.md` — текущий учебный план по DevOps и на каком этапе мы сейчас.
   Файл локальный (исключён через `.git/info/exclude`), в репозиторий не попадает.

## Правила, которые нельзя нарушать

- Не менять `name:` в compose-файлах и имена томов — база откроется пустой.
- Данные удаляет только `docker compose ... down -v`. Флаг `-v` без явной просьбы не использовать.
- Сервера нет, приложение живёт только локально (http://localhost:3000).
- Коммиты — короткие, по-русски, в отдельной ветке; пушит пользователь сам.
